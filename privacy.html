Règles de confidentialité

Cette application OAuth est utilisée exclusivement par son propriétaire, avec l'outil open source rclone, pour accéder à son propre compte Google Drive.

  • Aucune donnée personnelle n'est collectée, stockée sur un serveur, vendue ni partagée avec des tiers.
  • Les fichiers Google Drive sont transférés directement entre les serveurs de Google et l'ordinateur du propriétaire.
  • Les jetons d'accès OAuth sont stockés uniquement en local, sur l'ordinateur du propriétaire.
  • L'accès peut être révoqué à tout moment depuis myaccount.google.com/permissions.

L'utilisation des données reçues des API Google respecte les règles relatives aux données utilisateur des services API Google, y compris les exigences d'utilisation limitée.

Privacy policy

This OAuth application is used solely by its owner, with the open source tool rclone, to access the owner's own Google Drive account. No personal data is collected, stored on any server, sold or shared with third parties. Files are transferred directly between Google's servers and the owner's computer, and OAuth tokens are stored only locally on that computer. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
